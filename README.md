# আমানত হিসাব (GitHub Pages + Telegram বট)

## ১. GitHub-এ চালু করা
1. github.com-এ নতুন repository খুলুন (যেমন `hisab`)।
2. এই ৫টি ফাইল আপলোড করুন: index.html, manifest.webmanifest, sw.js, icon.svg, README.md
3. Settings → Pages → Branch: main, folder: / (root) → Save।
4. ১-২ মিনিট পর লিংক পাবেন: https://আপনার-নাম.github.io/hisab/
5. ফোনের ব্রাউজারে খুলে মেনু থেকে "Add to Home screen" দিন।

## ২. টেলিগ্রাম বট
1. টেলিগ্রামে @BotFather → /newbot → নাম দিন → টোকেন কপি করুন।
2. @userinfobot-কে /start দিন → আপনার Chat ID কপি করুন।
3. নিজের নতুন বটকে খুঁজে /start লিখুন (না করলে বট মেসেজ পাঠাতে পারবে না)।
4. অ্যাপে নিচে 🤖 টেলিগ্রাম → টোকেন ও Chat ID বসিয়ে "সেভ ও টেস্ট"।

## নিরাপত্তা
- টোকেন কোডে লিখবেন না। এটি শুধু আপনার ফোনের ব্রাউজারে থাকে।
- টোকেন কাউকে দেবেন না। ফাঁস হলে BotFather-এ /revoke দিন।

## নতুন ফোনে ফেরত আনা
লিংক খুলুন → 🤖 টেলিগ্রাম → টোকেন ও Chat ID দিন → "ফেরত আনুন"।
